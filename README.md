# Supermarket Sales Analysis Dashboard – Excel

## Project Overview

This project presents an interactive Supermarket Sales Analysis Dashboard developed using Microsoft Excel.

The project analyzes sales revenue, transactions, unit sales, average unit price, tax, customer types, gender, cities, branches, products, and business performance.

The project contains two dashboard views:

1. Supermarket Sales Dashboard
2. Supermarket Business Performance Dashboard

## Data Cleaning & Transformation

The raw supermarket sales data was cleaned and transformed using **Power Query** before creating the dashboards.

The data preparation process included:

- Reviewing the dataset structure
- Checking and correcting data types
- Cleaning and transforming columns
- Handling missing or inconsistent data
- Removing unnecessary data where required
- Preparing the dataset for analysis
- Creating a structured dataset for Pivot Tables and visualizations

## Data Analysis

After cleaning and transformation, the prepared data was analyzed using:

- Pivot Tables
- Pivot Charts
- Excel formulas
- KPIs
- Slicers
- Interactive dashboard visualizations

## Key Insights

- **Yangon** is the highest-revenue city among the three cities displayed.
- **Food and Beverages** is identified as the top product line.
- **Branch C** is identified as the top-performing branch.
- Revenue is distributed relatively evenly between **Member** and **Normal** customers.
- The dashboard enables analysis of **revenue, quantity, tax, products, customers, branches, cities, and gender** through interactive filters.
